## 3. Project Overview

This project aims to predict house prices using machine learning. The USA Housing dataset was analyzed and used to train a Linear Regression model. The project includes data preprocessing, exploratory data analysis (EDA), model training, evaluation, and a CLI application that allows users to predict house prices based on housing characteristics.


## 4. Problem Statement

The project solves the problem of estimating house prices. It helps predict the price of a house based on factors such as average income, house age, number of rooms, number of bedrooms, and population using a machine learning model
